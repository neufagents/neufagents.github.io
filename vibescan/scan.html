What this instant scan cannot see

It covers four static classes: hardcoded secrets, committed .env files, exposed service-role keys, and client-side secret names. Six more classes need a human pass on the full source (plus git history):

  • Database tables readable or writable without auth (RLS off)
  • Storage buckets left public
  • Admin or debug endpoints left open
  • Webhooks without signature verification
  • Auth enforced only on the frontend
  • Dependencies with known vulnerabilities

The free sample review covers these - one repo, human pass, 24-48 hours. The full 10-class audit is $500.
