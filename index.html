MCP Triage

mcp-triage v0.2.0

A triage for broken MCP setups. One command scans the config files of the eight agent clients on your machine, explains what is broken in plain English — and repairs the mechanical class (comments, trailing commas) with a parse-gated write and a backup.

  • Eight clients — Claude Desktop, Claude Code, Codex, Cursor, VS Code, Windsurf, OpenClaw, dsh
  • Checks that matter — broken JSON/TOML, commands not on PATH, missing env vars, relative paths, transport mismatches, cross-client drift
  • Conservative by design — only provably safe fixes are written; everything else gets an explanation and a hint, never a guess
  • Runs as an MCP server — npx mcp-triage serve lets your agent client run triage itself (triage_scan, triage_fix)

dsh-healthcheck

dsh-healthcheck v0.1.1

A read-only health check for your DeepSeek Harness session library. It spots the two things that quietly kill long agent sessions — runaway size (OOM risk) and crash-torn logs (unclosed turns that resume silently repairs).

  • Library scan — totals, largest sessions, size & event-count warnings
  • Deep inspection — crash-tail detection, tool-call/result pairing, event distribution
  • Read-only — it never writes a byte of your data
